## About

I'm a University of Toronto student pursuing **Computer Science Specialist**, **Data Science Specialist**, and **Statistics Minor** programs. I develop software in **Java and Python** and use **R** for statistical analysis and reproducible data workflows.

My work focuses on algorithm design, object-oriented systems, and software reliability: recursive game-tree search, simulation frameworks, and desktop applications with clearly separated application and domain logic. I'm currently contributing to **LogiCoach**, a team-built digital logic learning tool, with a focus on AI-assisted circuit generation, design validation, and truth-table verification.
